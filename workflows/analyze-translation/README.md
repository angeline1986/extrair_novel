# Analyze Translation

Fluxo para análise e correção de tradução usando o script existente.

## Uso

- `npm run analyze:translation analisar`
- `npm run analyze:translation corrigir`

## Pastas

- `input/` — arquivos originais e traduzidos para análise
- `output/` — arquivos corrigidos gerados
- `reports/` — relatórios de revisão

> Esta pasta usa um wrapper para `src/translation/Analisar_traducao_docx.js`.
