# Extract EPUB

Fluxo para extrair EPUBs em arquivos DOCX usando o script existente.

## Uso

- `npm run extract:epub [epubPath] [outputDir]`

## Pastas

- `input/` — coloque EPUBs aqui
- `output/` — saída de DOCX gerados
- `logs/` — logs de extração

> Esta pasta usa um wrapper para `src/extract/extract-epub-arcs-to-docx.cjs`.
