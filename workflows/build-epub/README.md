# Build EPUB

Fluxo para gerar EPUB final a partir de arquivos DOCX usando o gerador existente.

## Uso

- `npm run build:epub`

## Pastas

- `input/` — arquivos DOCX ou pastas de capítulos de entrada
- `output/` — EPUB resultante
- `assets/` — capas, imagens e metadados

> Esta pasta usa um wrapper para `src/epub/epubGenerator.js`.
